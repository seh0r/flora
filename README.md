# Цветочный магазин «Лепесток»

Проект по практике ПМ.05, тема №13.
Оксененко Марк Сергеевич, группа ОКИП-22309МОрвмп.

Сайт написан на HTML, CSS, JavaScript и PHP. База данных — MySQL/MariaDB, запуск через XAMPP.

## Запуск

1. В XAMPP включить Apache и MySQL.
2. Открыть http://localhost/lepestok-practice/.

На этом компьютере база уже настроена.

При переносе на другой компьютер установить XAMPP в `C:\xampp`, скопировать проект в `C:\xampp\htdocs\lepestok-practice`, включить Apache и MySQL и запустить `INSTALL.bat`. Установщик создаст базу и добавит примеры заказов. Повторно запускать его для существующей базы не нужно.

## Работа с сайтом

Покупатель выбирает букет, указывает количество, адрес, дату и время доставки. После оформления заказ появляется в разделе «Мои заказы». Там можно посмотреть его статус и историю изменений.

Администратор открывает раздел «Управление», просматривает заказы и меняет их статусы: новый, подтверждён, в доставке, выполнен или отменён. Для поиска заказов есть фильтры.

Оплата предусмотрена при получении — наличными или картой курьеру.
